## What you can and cannot reach

Fannie Mae publishes **no public API contract**. There is no OpenAPI, no AsyncAPI, no GraphQL SDL, no
Protobuf, no WSDL, no Postman collection and no MCP server at any public URL. The API catalog, the
reference documentation and the specifications live inside the Developer Portal and require a
registered account; an unauthenticated request to the portal's own data API 302s to the Fannie Mae
single sign-on authorization server. Production API access is granted per application under the
Software Subscription Agreement and administered through Technology Manager — it is not self-service.

Do not attempt to call a Fannie Mae API without credentials. The enterprise gateway host
(api.fanniemae.com) answers HTTP 400 to every anonymous request.
